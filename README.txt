СВАРОГ — VIP-каталог, версия 7

64 комплексных предложения: по 16 в каждом направлении. На широком экране сетка 4×4, на планшете 3 колонки, на телефоне 2. При нажатии открывается описание, базовый состав и условия расчёта.

Все цены — предложенные стартовые ориентиры, а не утверждённая подрядчиком смета. Перед публикацией владелец должен подтвердить услуги, цены и доступность комплектаций. Площадь, длина трасс и количество приборов определяются для каждого объекта. Оборудование и материалы не включены.

Каталог и цены редактируются в catalog.js. У каждой услуги есть поле icon: новые индивидуальные золотые иконки можно поставить сюда. Пока используются присланные иконки направлений.

Реальный канал заявок ещё не указан. В окне услуги есть кнопка копирования запроса; она не отправляет заявку.

Открывайте через HTTP/HTTPS для WebGL. Без WebGL работает статичный фон. Сохранены анимации первого экрана и раскрытия четырёх частей.

Проверены синтаксис JS, число карточек, нижний порог цен и наличие иконок. Визуальная проверка в браузере не выполнена.

Версия 8: фон главного экрана заменён на присланное небо с птицами. Текстура WebGL и статичный фон одинаковые. На главном экране верхнее меню скрыто, внутри направлений отображается.
